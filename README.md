# Интерактивные конспекты для подготовки к ЕГЭ по информатике

В данном репозитории будут собраны мои конспекты, интерактивные лекции в формате блокнотов Jupyter Notebook.
Разделение будет как по основным темам кодификатора, безотносительно конкретных номеров заданий, так и по отдельно взятым номерам с разборами
типовых задач из открытых источников ("Решу ЕГЭ", сайт ФИПИ, бумажные сборники и т.д.). Постараюсь структурировать каждый такой конспект подробной 
лекцией, в красиво оформленном Markdown'е, набором задач с полным решением на Python, а также вопросами по разобранной теме и "домашними заданиями".
